# Steal a Brainrot Hub — Delta Script

ساخته‌شده مثل نمونه‌ی Kurdhub که فرستادی، ولی تمیز و بدون ابفسکیت (متن بازه، خودت می‌تونی ویرایشش کنی).

## دو راه استفاده

### راه ۱ — مستقیم توی دلتا (ساده‌ترین، بدون گیت‌هاب)
1. فایل `StealABrainrot.lua` رو باز کن، کل متنش رو کپی کن
2. دلتا رو باز کن، وارد بازی Steal a Brainrot شو
3. متن رو توی ادیتور دلتا پیست کن و Execute بزن
4. منو وسط صفحه میاد — درگ‌شدنیه، با `-` کوچیک میشه، با `X` بسته میشه

### راه ۲ — مثل Kurdhub، فقط یه خط loadstring
1. یه ریپوی عمومی توی گیت‌هاب بساز
2. فایل `StealABrainrot.lua` و `loader.lua` رو توش آپلود کن
3. توی `loader.lua` عبارت `YOUR_GITHUB_RAW_URL` رو با آدرس raw ریپوی خودت عوض کن
4. این یه خط رو بده به هرکی می‌خوای / خودت توی دلتا بزن:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/YOURNAME/YOURREPO/main/loader.lua"))()
```

## قابلیت‌ها
- **WalkSpeed + JumpPower** — با اسلایدر +/- 
- **Speed Boost** — سرعت بیشتر برای برگردوندن براینروت دزدیده‌شده به بیس
- **Fly** — با سرعت قابل تنظیم (با جوی‌استیک موبایل هم کار می‌کنه)
- **Noclip** — رد شدن از دیوار
- **Infinite Jump** — پرش بی‌نهایت
- **Anti Ragdoll** — زمین نمی‌خوری / رگدال نمیشی
- **Instant Prompt** — نگه‌داشتن E / دکمه حذف میشه، تعامل فوری میشه
- **Auto Collect Cash** — جمع‌کردن خودکار پول توی بیس خودت
- **Auto Lock Base** — قفل‌کردن خودکار بیس خودت (از پرامپت Lock توی بیست استفاده می‌کنه)
- **Teleport to My Base** — تلپورت به بیس خودت
- **Player ESP** — دیدن پلیرها از پشت دیوار با اسم
- **Brainrot ESP** — دیدن براینروت‌های قابل تعامل با اسمشون

## Auto Finder (`AutoFinder.lua`)
فایندر جدا و تخصصیه — یا از دکمه‌ی **Open Auto Finder** توی منوی هاب بازش کن، یا مستقیم:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/njkhjgcd/steal-a-brainrot-script/main/AutoFinder.lua"))()
```

کارش:
1. کل سرور فعلی رو اسکن می‌کنه — همه‌ی براینروت‌های قابل تعامل (بیس‌ها + کمربند) رو از روی درآمد $/s و کمیابیشون می‌خونه و رتبه‌بندی می‌کنه
2. کمیابی رو می‌تونی تنظیم کنی: Any تا OG — ترتیب درستش: Common < Rare < Epic < Legendary < Mythic < Brainrot God < Secret < OG. پیش‌فرض: **Brainrot God به بالا**
3. حداقل درآمد $/s هم قابل تنظیمه (Any / 1K / 10K / 100K / 1M / ... )
4. هدف رو پیدا کنه: هایلایت طلایی + اسم و درآمد روش میاد، نوتیفیکیشن میده، و اگه Auto Teleport روشن باشه می‌پره پیشش؛ Auto Steal هم تلاش می‌کنه همون‌جا بدزدتش
5. توی این سرور هدف نباشه و Auto Server Hop روشن باشه: ۱۵ ثانیه صبر و بازبینی می‌کنه، بعد میره یه سرور عمومی شلوغ‌تر (بیس بیشتر = هدف بیشتر)، سرورهای قبلی رو تکرار نمی‌کنه، و توی سرور جدید خودش خودکار ادامه میده (تنظیماتش ذخیره میشه)
6. دکمه‌های دستی هم داره: **Find Best Now** (بهترین همین سرور رو همین الان نشون میده) و **Server Hop Now**

نکته‌ی فنی صادقانه: هیچ اسکریپت توی بازی نمی‌تونه براینروت‌های سرورهای دیگه رو از بیرون ببینه — دیتای سرورهای دیگه فقط تعداد پلیره. برای همین فایندر واقعی یعنی همین چرخه: اسکن این سرور → نبود؟ هاپ → اسکن سرور بعدی. هر هابی که ادعای «دیدن براینروت سرورهای دیگه» می‌کنه، داره دروغ میگه.

## نکته‌ی مهم و صادقانه
- بازی PlaceId اصلیش `109983668079237` هست — چک شده.
- قابلیت‌های کلاینت‌ساید (اسپید، فلای، نوکلیپ، ESP، Instant Prompt) قطعی کار می‌کنن چون به سرور ربطی ندارن.
- Auto Collect / Auto Lock / Teleport to Base به ساختار بیس و پرامپت‌های داخل بازی تکیه دارن؛ اگه بازی آپدیت بده و اسم/ساختار پرامپت‌ها عوض بشه، ممکنه اون چندتا نیاز به آپدیت داشته باشن. موقع تست اگه یکیش کار نکرد، بگو کدومه تا همونو فیکس کنم.
- «اتو استیل جادویی» که بعضی هاب‌ها تبلیغ می‌کنن معمولاً یا فیکه یا سریع بن میده؛ این اسکریپت اون ادعا رو نمی‌کنه — سرعت + Instant Prompt + نوکلیپ + تلپورت به بیس، ترکیب واقعی دزدیه.
- با اکانت اصلی نزن؛ روبلاکس اسکریپت رو خلاف قوانینش می‌دونه و ریسک بن با اکانت فرعی کمتر اذیتت می‌کنه.
